# Uniswap V3 Module

Arrakis Private Vault module integration with Uniswap V3.

Vault Type(s): Private Vault

Features:

- manage multiple V3 liquidity positions in a aggregated/batched way with nice interfaces
- configure and control automated LP strategies tailor designed for V3
- optionally enable direct RFQ with the vault (policed by your oracle of choice)
- supports any Uniswap V3 exact fork, like Oku Trade or Sushiswap.

## Deployments

Networks: Ethereum Mainnet, Base, Arbitrum, BNB Chain, Plasma
